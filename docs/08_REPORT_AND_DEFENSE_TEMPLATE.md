# 08｜结题报告与答辩模板

本文件是填写结构，不是结题报告成稿。所有“待实测”保留为空，直到实际运行、保存配置和预测后才填。开题正文见[02](02_PROJECT_PROPOSAL.md)。

## 1. 报告标题与摘要

**标题：预训练视觉语言模型驱动的图文语义匹配评估与预算约束重排优化。**

摘要模板：本实验围绕图文语义匹配的量化评估与优化，使用【数据版本与固定划分】比较【实际完成的方法】。主任务为【T2I 候选库与查询规模】，采用【指标口径】。在单张【A100 实际显存】上，最终方法取得 R@10【待实测】，相对基线变化【待实测】个百分点。错误分析表明【有证据支持的发现】。研究扩展在【实际预算】下表现为【待实测】，其局限为【待分析】。未运行的研究扩展不写进摘要的已完成成果。

## 2. 建议正文结构

### 第一章 任务、背景与研究问题

说明实验五目标和本地资源，给出 RQ1–RQ4 中实际完成的部分。近期文献只写与方法选择有关的认识，不堆砌“顶会模型”名词；明确 WISER/PinPoint 与本项目的任务区别。

### 第二章 数据、真值与实现

写清数据来源、val/test 图片与文本数、候选库、五描述处理、配对映射、数据审计和预处理。说明上游预训练覆盖未知。提供环境、模型 revision 和运行命令。

### 第三章 方法

分别描述 B0/B1、实际做过的 F1，以及研究版 R1/G/RAND。图中标注是否访问标签，确保门控只看初检分数。模型升级与门控策略的对照分开。

### 第四章 指标与结果

先定义 hit-style R@K、NDCG 和置信区间，再给数值。统计含失败回退查询，不用成功子集代替完整测试集。

### 第五章 错误分析与诊断

统计保持正确、修复、退化、持续失败；展示不同错误类型。改写和人工多正例审查作为独立诊断，注明样本来源与标注规则。

### 第六章 结论与限制

回答是否在固定协议上达到 85%，哪些优化有证据支持，预算代理量和实测时间是否一致。没有实现的内容写展望，不写成果。

| 1–2 分钟 | 固定数据和命中式 Recall/NDCG 的定义 |
| 2–3 分钟 | 近期论文如何影响两阶段与按需计算设计 |
| 3–5 分钟 | 实际结果：基线、优化、同预算对照 |
| 5–6 分钟 | 一个被修复案例和一个退化案例 |
| 6–7 分钟 | 稳定性、成本口径、改写诊断（已做时） |
| 7–8 分钟 | 结论、局限、未完成部分 |

## 6. 常见追问的回答依据

“为什么不训练？”——研究对象是已有预训练表示下的评估与排序优化，训练不是当前问题的必要前置。

“为什么用新模型后提高不算你的算法提升？”——模型替换单列为整体配置升级；门控研究固定初检器、候选与重排器，才用于分析策略效果。

“为什么不把所有查询交给大模型？”——要用实际质量—候选对数和时间比较回答，不能只说“大模型太贵”。

“85% 能否代表真实语义准确率？”——只代表这里固定配对真值、方向与图库下的命中指标；人工与改写诊断揭示额外语义限制。

“门控输给随机怎么办？”——如实报告，说明分数间隔信号无效或不稳定，不删除随机对照。
