# 07｜风险登记与设计决策

## 1. 当前明确选择

| 决策 | 采用方案 | 原因 | 何时重新考虑 |
|---|---|---|---|
| 范围 | 只做实验五 | 用户明确约束 | 用户变更范围时 |
| 初检 | 冻结 CLIP / SigLIP 2 | 避免从零训练，先建立强基线 | 固定协议表现异常且实现已核对 |
| 检索方式 | 精确矩阵相似度 | 1000 图像规模无需 ANN | 扩展到真正大图库且任务要求改变 |
| 研究变量 | 固定初检器，研究 Top-50 重排及门控 | 能隔离排序策略影响 | 单卡时间不允许时退回基础版 |
| 本地重排 | Qwen3-VL-Reranker-2B | 官方相关性评分封装 | 小试显示不兼容或净收益不足 |
| API | 错误解释、改写为主 | 避免费用扩大与真值污染 | 明确预算后增加独立 API 对照 |
| 训练 | 第一轮不做 | 当前问题可由冻结模型评估回答 | 不在本轮隐式增加 |
| 公开内容 | 文档、配置草案、脱敏结果 | 不传播数据与密钥 | 明确确认使用条件后 |

模型和论文相关依据见[调研](01_LITERATURE_REVIEW.md)。这些是项目取舍，不是对所有模型普遍优劣的结论。

## 2. 风险与处理

| 风险 | 后果 | 应对与披露 |
|---|---|---|
| 外层数据 split 被误读 | 候选库变为 31k，指标不可比 | 使用记录内部划分与固定 ID 清单校验 |
| 图文映射错位 | 成绩严重失真 | 显式 ID 键、正例存在断言、手工核对样本 |
| 处理器混用 | 不可解释的性能降低 | 各模型使用自身 processor 与 revision |
| 从验证结果推断必然达标 | 结果承诺失实 | 只报告实际 test 成绩，参考论文另列 |
| 测试集调参 | 最终成绩不再独立 | 冻结配置；探索性再运行明确标注 |
| 预训练数据覆盖未知 | 泛化声明过强 | 使用“无本地任务训练”，不声称无上游污染 |
| 固定配对标签不覆盖所有合理图 | 语义解释与主指标不一致 | 官方主表与人工诊断分开 |
| R@10 已近上限 | 改进空间很小 | 同看 R@1、NDCG、错误类型，不更换容易数据 |
| 重排增加错误 | 质量反降 | 统计修复和退化，保留 B1 回退选项 |
| 分数间隔门控无效 | 不优于随机预算分配 | 同预算随机对照，承认启发式失败 |
| 预算门控遇分布漂移 | 实际触发比例变化 | 冻结阈值并报告实际比例、硬预算截断 |
| 缓存模拟冒充加速 | 效率结论不可信 | 分开测量与反事实成本，最终策略独立计时 |
| GPU 显存或机时不足 | 研究扩展延期 | 减 batch；控制候选数前先注册变更；不默认换全套架构 |
| API 输出幻觉 | 错误分析被误导 | 可见证据、unknown、人工复核 |
| API 或图片泄露 | 公开数据与账户风险 | 最小化上传、环境变量密钥、忽略原始日志 |

## 3. 不能使用的结论表述

“SigLIP 2 论文达到某成绩，所以本实验已经达标”不成立。

“WISER 在 CIR 上提升很多，所以本项目门控必然有效”不成立，两者任务与实现不同。

“重排器给出 0.9，所以该图有 90% 概率是正确答案”未经校准，不能这样解释。

“我们只花四分之一模型时间”，若只是从全量缓存模拟四分之一查询，不能这样表述。应写“该策略理论使用四分之一候选对；实际时间尚未独立测量”。

“Top-10 中找到任意一个正确项，所以 10 张图片都准确”混淆命中式召回和精确率。

“负结果说明实验失败，所以需要删掉该方法”不成立；有适当控制和证据的负结果同样是分析结果。
