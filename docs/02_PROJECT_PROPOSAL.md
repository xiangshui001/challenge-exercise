# 02｜课程实验开题报告

## 一、基本信息

**课题名称：预训练视觉语言模型驱动的图文语义匹配评估与预算约束重排优化**

课程实验：实验五——语义匹配准确率的评估与优化。项目成员、学号、课程名称、指导教师、开题日期：由使用者填写。本报告为拟实施方案；结果与结论须在实际运行后补充，不包含虚构实验成绩。

## 二、研究背景与意义

图文检索需要将自然语言描述与视觉内容进行匹配。对于同样包含人物、动物或交通工具的图片，仅识别主体类别往往不足以区分颜色、数量、动作和关系。课程材料第 14 页将量化评估、错误分析与优化作为实验五的主体，并提出 Top-10 召回率目标；第 21 页进一步列出 Recall@K 与 NDCG@K。

本课题不重新开发完整检索系统，而是在可控数据与资源下研究一个明确问题：利用已有视觉语言模型获得较强初检能力后，能否通过低成本优化和有限的图文交互评分，改善排序质量，并解释改进与失败的原因。

近期工作为该研究提供依据：LamRA 将检索与重排分层；MM-Embed 提醒大型多模态模型并不必然是最优初检器；WISER 与 PinPoint 分别提供自适应计算和更细致评估的启发。这些论文的原任务和方法并不完全相同，本课题只迁移适合单卡离线实验的思路，具体关系见[文献调研](01_LITERATURE_REVIEW.md)。

## 三、研究目标与问题

### 3.1 实施目标

建立可复现的图文检索评测流程，完成预训练模型基线、优化方法、逐查询错误分析和独立测试。主要技术目标是在固定 Flickr30K 测试协议下检验文本检索图像 R@10 是否达到 85%，同时报告 R@1、R@5、NDCG@10 与不确定性。若未达到，如实给出原因与改进方向，不改变候选库或筛选查询来制造达标结果。

### 3.2 研究问题

| 编号 | 问题 | 对应验证 |
|---|---|---|
| RQ1 | 预训练模型升级是否改善语义匹配，改善哪些错误？ | CLIP 与 SigLIP 2 使用完全相同的数据与指标 |
| RQ2 | 固定初检器后，候选重排是否带来净收益？ | SigLIP 2 与同候选库的全查询 Top-50 重排比较 |
| RQ3 | 少量困难查询重排能否优于相同预算的随机分配？ | 按边界歧义选择 vs 同数量随机选择，使用同一重排器 |
| RQ4 | 正式配对指标较高时，查询改写是否仍导致明显退化？ | 预先抽样、人工确认的改写查询诊断 |

RQ1 属于基础版，RQ2–RQ3 是推荐研究扩展，RQ4 是资源允许时的诊断扩展。阶段性完成不以所有问题都出现正面结果为条件。

## 四、研究内容与技术路线

### 4.1 数据与基准评估

采用 Flickr30K 的既有 Karpathy 划分，计划使用 1000 张验证图像及 1000 张测试图像，每张图像五条原始英文描述。下载后以实际划分文件和图片清单校验数量，不通过外层文件分区名称猜测标准测试集。文本检索图像时，5000 条独立文本在 1000 张图像中检索；反向检索使用 1000 张图像查询 5000 条文本。正式评测与人工补充诊断分开记录。[D1–D3]

### 4.2 预训练模型与低成本优化

使用 `openai/clip-vit-base-patch16` 建立基线，使用 `google/siglip2-so400m-patch14-384` 作为强基线。两个模型分别编码并缓存图像和文本向量，以归一化内积完成精确检索。需要时在已缓存排名上测试 RRF 融合，避免新增训练。[P0][T1][P6]

这一步的目的不是提出新的编码器，而是建立稳定的质量基线，使后续排序策略可以在相同条件下比较。

### 4.3 图文交互重排

在固定 SigLIP 2 初检结果上取 Top-50 候选，用预训练 Qwen3-VL-Reranker-2B 逐对计算查询文本与候选图像的相关性。先进行 100 条验证查询的小试，评估净收益与耗时，再决定是否扩大。候选输入不带人工配对描述和正例标记。[P3][T2]

与初检相比，重排能够利用查询和图片的联合输入，但也可能引入新错误。本课题记录修复数与退化数，不把额外计算等同于必然改善。

### 4.4 预算约束选择性重排

拟采用 Top-10 边界分数间隔构建启发式难度信号：边界间隔较小时，对该查询触发一次 Top-50 重排。阈值仅从验证集确定；推理时不读取标准答案。比较不同预算水平，并加入同实际查询数量的随机门控对照。

该策略受按需验证思路启发，但不复现 WISER 的组合输入、图像生成和多轮细化。本项目的门控指标是待验证假设，不能把分数间隔解释成经过校准的错误概率。[P4]

### 4.5 错误解释与语义鲁棒性

将错误归为主体、数量、属性、动作、关系、文本歧义和标注局限等类别。模型 API 可以辅助输出可见证据与结构化判断，人工复核最终类别。选取固定查询进行保真改写，单列其检索指标变化，避免只凭高 R@10 得出“完全理解语义”的结论。[P5]

## 五、实验设计与统计方法

主指标为命中式 T2I R@10，辅助指标为双向 R@1/5/10、NDCG@10。I2T 每个查询具有五条正例文本，命中式召回与集合召回率分别定义，不混称“准确率”。

验证集用于预处理检查和参数选择；最终测试前冻结候选数量、融合权重、门控阈值及模型版本。基线和已注册对照统一在测试集评估，不再根据测试结果反复调整。可将验证图像分为调参组与确认组，二者共享完整验证图库，防止候选规模变化。

统计分析以图像为分组进行 2000 次 bootstrap：T2I 每次一起重采样同图的五条描述，图库保持固定；方法差异采用配对重采样。报告置信区间、修复和新增错误数量。全量重排缓存模拟预算策略时，分别记录真实缓存生成成本与模拟策略成本；后者不冒充已测加速。

详细公式、方法编号与消融控制见[实验协议](03_EXPERIMENT_PROTOCOL.md)。

## 六、预期特色与贡献边界

课题的预期特色是形成“强基线—局部交互—计算分配—错误解释”的可复现实验，而不是重写现有模型。具体交付包括统一的图文检索评测协议、质量与重排预算的对照结果、按错误类型分析的证据以及可复用的运行记录。

不宣称发现新的基础模型结构，不预设门控策略具有理论最优性或普遍有效性，不将他人论文的思想标为本项目原创。若门控不优于随机对照，该结果同样能够说明启发式难度信号的局限，构成有效分析。

## 七、可行性与资源安排

现有资源为单张 A100 与模型 API。使用冻结权重顺序推理，不同时加载全部模型。Flickr30K 1000 图像与 5000 文本的相似度矩阵为 500 万元素，FP32 约 20 MB，采用精确矩阵检索即可。重排成本由候选对数量决定，先测每秒图文对数与峰值显存，再制定上限；不依据 A100 名称猜测完整运行时间。

基础版计划约 3 个工作日，研究版总计约 5–7 个工作日，并预留下载和环境问题缓冲。这是项目估算而非实测承诺；任务拆分和停止条件见[日程与预算](05_TIMELINE_AND_BUDGET.md)。

## 八、预期成果与验收

| 成果 | 验收依据 |
|---|---|
| 数据与环境清单 | 样本划分校验、图片可用性、模型和依赖版本 |
| 正式评估结果 | 汇总指标、逐查询预测、可重算结果 |
| 优化对照 | 固定协议下的基线与至少一种优化尝试 |
| 错误分析 | 同时展示修复、退化与未解决案例 |
| 研究扩展 | 启用时包含全量、选择性、随机同预算对照 |
| 书面报告 | 说明达标情况、统计不确定性、局限与引用 |

达到 R@10≥85% 与完成研究过程分别记录。最终报告不能只有“模型很强”的定性描述，也不能只有一张没有样本、协议和配置依据的指标表。

## 九、主要风险与应对

数据划分误读可能导致图库错误，需先校验 ID；预处理差异可能造成异常低分，需使用模型自身处理器；强基线可能接近指标上限，需同时观察 R@1 与 NDCG；重排可能无效，需保留负结果并及时停止扩展；API 可能发生幻觉或费用超支，需盲审复核、缓存和硬预算。预训练数据覆盖无法完全核验，报告不声称测试样本对上游模型绝对未见。
