# M0｜问题存在性诊断：义项、语义关系与视觉证据

**状态**：2026-11-02 方案冻结前草案；尚无 M0 实验结果。目标是决定新的研究主线是否有可靠证据，不是提前证明“辞书增强一定有效”。本阶段优先公开数据与冻结预训练模型，不从零训练。

## 1. 核心问题与假设

- **H1 等价表达稳定性**：同一图像，两条语义等价但措辞不同的正确描述，是否经常被模型区别对待，甚至其中一条不如困难错误描述？
- **H2 关系类型与方向**：模型能否区分同义/上位-下位（方向性蕴含）/矛盾/不蕴含等关系，尤其关注数量、主体-客体、动作和否定？
- **H3 视觉证据边界**：模型是否会将“词典中常见/语义上合理”的判断误报为“图像证明”，而不能区分支持、冲突与证据不足？
- **H4 知识是否有独立价值**：相同模型/样本/调用预算下，显式有类型的义项关系是否优于等信息量的自然语言释义？是否真正依赖图像？

H1–H3 用于确认问题；H4 是后续最小知识干预。暂不宣称新的图文网络结构或 CCF A/B 论文已经成立。

## 2. 第一轮数据（目标约300个评测单元，不是300张新图片）

| 来源 | 目标抽样 | 独立问题与指标 |
|---|---:|---|
| SugarCrepe++（NeurIPS 2024 D&B） | 120 | 一图两条等价正描述＋一条困难负描述；成对排序成功率、等价性一致性与错误类别 |
| SNLI-VE，优先核验校正版 e-SNLI-VE | 120（蕴含/矛盾/中立各约40） | 图像-假设三类标签；准确率、宏平均F1、混淆矩阵及中立误报率 |
| Visual-WSD（SemEval 2023） | 40 | 歧义词/简短上下文→十张候选图；top-1准确率、不同义项错误 |
| Winoground（CVPR 2022，可选） | 20 | 图片-句子配对组合判别；保留官方评分口径 |

用官方可追溯身份及许可，实际条数按可用、审核通过且预先记录的样本为准。不能因为难度或模型失败对测试集重新抽样。**上述基准指标不可直接平均为一个“语义能力分”。**

样本首轮采用分层/固定 seed=2026 抽取；按原始图像或原始评测组分开探索和确认（建议各约60%/40%，比例按数据可用性记录）。不得把等价文本拆到探索和确认两边造成泄漏。下载的官方 test 若已经是基准测试集，内部划出的探索组应明确叫 exploration，不可冒称仍是未触碰的官方独立 test。检查跨数据集重复图像与上游训练污染风险；无法核验预训练是否见过样本时如实说明。

## 3. 先做原始基线，不改数据和模型

优先复用已有 SigLIP-base S0（见 PR #5），再选择 CLIP、SigLIP 2 中至少一种独立双塔对照；经成本小试后可加入 Qwen3-VL 联合判断。所有使用固定权重、固定处理器、固定提示/版本、同一评测单元。低成本先做20样本冒烟，确认模型读取图像而非仅看文件名/文本。

各模型只报告**适用的指标**：
- SugarCrepe++：正确描述是否均胜过困难负例，成对差值/一致性；不得只看两个正例相似度绝对差。
- SNLI-VE：有三分类输出的模型用官方标签计算三分类；SigLIP 原始图文相似度**不是**三类概率，可做标签分布/排序诊断，若训练/校准判别头则必须另列方法和调参数据，不冒充零样本三分类。
- Visual-WSD：按官方十候选 top-1 与同候选输入；不能把 gold 义项或人工选择直接写进模型提示。
- Winoground：按官方 image/text/group score，不把两个方向乱平均。
- 全部保留逐样本原分数/预测/标签/有效性/失败原因、模型revision/运行命令/推理预算。按原始组配对比较，汇总报告置信区间与异常类别。

## 4. 人工核验与误差归因

先固定抽样，再审标注。至少对中立、矛盾、词义歧义、模型分歧和异常结果进行双人独立核验；无法双人时标记 single_review，不得声称双盲一致性。标注类别：等价、方向性蕴含、冲突、不可判断、视觉区域/角色错误、原标注歧义、其他。记录证据和分歧，未知标 unknown。自动API辅助只能提供候选解释，不能代替真实标注或偷偷改官方 gold。

## 5. 辞书的最小干预实验（无需训练）

从探索集选一个预注册的困难子集，不根据最终确认集分数筛选；冻结后在确认集复核：

- **K0**：原始查询与图片，无额外知识。
- **K1**：相同来源/候选义项的**普通自然语言释义文本**。
- **K2**：来自同一批知识的**义项ID、关系类型、方向及适用条件**，用最简结构呈现。
- **K-random / K-shuffle**：长度与形式尽量匹配的错误/打乱关系，检验收益是否只来自额外Token。
- **文本-only/图像替换**：检验模型是否真的利用了视觉证据。
- **Oracle上限（仅诊断）**：人工正确义项/关系单独列出，禁止与实际系统成绩混合。

K1/K2 尽可能控制知识范围、Token/调用预算和模型、提示长度；有差异则量化。不得把根据 gold 选定的唯一正确义项当作 K2 的可用输入，否则泄漏答案。关系必须有可核验辞书来源与许可；WordNet/HowNet/语义关系现成知识优先，SenseRange 自建研究结构只能在单独报告来源、验证后加入。

**即使K2优于K0，也必须和K1、K-shuffle比。** 只有 K2 超过等知识量文本，才能初步支持结构关系的独立价值；即使如此也需之后跨数据集、未见组合复现。

## 6. 本阶段产物与判定门

必须交付：
1. 可复现数据manifest（含split、sample_id、图像/文本关联、来源许可与checksum）及数据审计；
2. 指标实现和至少一项手算/合成单测；真实预训练模型结果与逐查询输出；
3. 经过核验的错误样本与分类型分析（修复/新增错误/未知不可混淆）；
4. K0/K1/K2与打乱关系/视觉消融对照（若资源不足，要明确哪项尚未跑）；
5. M0_REPORT.md：问题成立、尚无足够证据或被否定的分类结论；决定下阶段训练语义关系模块、视觉连接器，还是停止该研究路线。

**不是硬要“全部成立”。** 若只有个别孤例、标签噪声主导，或K2没有超过等信息量文本，应停止复杂模型训练，重新界定问题。

## 7. 明确不做的事情

本轮不从零训练大视觉模型、不做SigLIP微调或Qwen全量Top-50重排、不创建新图库、不进行领域服务部署。可以小试调用API辅助审核，但批量付费前需确定预算上限。旧Flickr30K 95.84%为 PR #5 报告的**验证集历史成绩**，不是本诊断结果。
