# M0 研究判断报告：真实失败成立，当前辞书结构干预未获支持

2026-11-02。对应 Issue #7；不训练新模型。结论只适用于本次冻结样本、三个指定 checkpoint 和单一提示，不代表所有视觉语言模型，也不是完整官方榜单成绩。

**主要判断**：两个双编码器均出现可复算的同义改写排序不稳定，且找到跨模型重复的清晰义项/空间关系错误。Qwen 的三分类结果显示明显的冲突漏判与部分证据不足误判，但提示约定和标注噪声仍影响归因。**当前 WordNet 直接注入方案没有证明结构化关系优于等信息量普通释义，更没有证明关系方向被利用。暂不启动新训练。**

## 1. 证据范围与执行状态

先提交 [预注册](20_M0_PREREGISTRATION.md)，冻结抽样、模型、提示、指标、知识规则与控制，再推理。代码在 main `b50f74c` 上建立独立研究分支；旧 PR #3/#5、旧服务器数据、模型、S0 缓存和结果均保留。旧 S0 的 5,070 个验证查询命中数独立核对一致，不能将其检索 Recall 当作本轮语义能力证据。

| 数据 | 探索 / 确认 | 实际输入与处理 |
|---|---:|---|
| SugarCrepe++ | 70 / 50 | 五类各 24 单元；每单元一图、两个正描述、一个负描述 |
| e-ViL e-SNLI-VE test | 72 / 48 | 三类各 40，图像互不重复；只输入 hypothesis，不输入 premise、解释或 gold |
| English Visual-WSD test v1.1 | 21 / 15 有效 | 原注册 24 / 16；字节审计在推理前隔离 4 单元，不补抽；每单元 10 候选 |

全部 640 个注册图像文件可读、身份已记录；保留排除项后无跨单元有效字节重复。文件名之外的字节检查确实发现两组重复图片，说明仅按文件名划分不足。未做感知近重复和预训练污染审计，不能声称完全无泄漏。

模型为 SigLIP-base-p16-224、OpenAI CLIP ViT-B/32、Qwen2.5-VL-3B-Instruct，revision、权重 SHA256、处理器、精度、依赖和 UUID 均已记录。实际只用授权 GPU 4/5。每模型先 20 探索单元小试；Qwen 首次因缺 torchvision 在生成前失败，补齐隔离依赖后重试，未改样本或提示。正式结果无缺失、无非法输出、双编码器无文本截断；排除单元不进入主分母。

[公开证据目录](../results/m0-20261102/)包括原始逐项分数/输出、清单、图片指纹、运行元信息、汇总、知识审计和 AI 复核。[复现说明](22_M0_REPRODUCE.md)提供从原数据重建和无模型复算两种路径。官方标签未因复核意见而修改。

## 2. 双编码器：同义表达、关系和义项

ITT 严格要求两个正描述分数都高于负描述；XOR 表示只有其中一个高于负描述。TOT 使用官方的两次文本相似度比较，不把它解释为三分类蕴含概率。区间为 seed=2026、2,000 次单元 bootstrap 的 95% 百分位区间。

| 指标 | SigLIP 探索 | CLIP 探索 | SigLIP 确认 | CLIP 确认 |
|---|---:|---:|---:|---:|
| SugarCrepe++ ITT | 64.29% | 62.86% | **64.00% [50.00, 76.05]** | **52.00% [38.00, 66.00]** |
| 同义改写 XOR | 20.00% | 22.86% | 22.00%（11/50） | 32.00%（16/50） |
| 两正例均败给负例 | 15.71% | 14.29% | 14.00% | 16.00% |
| TOT | 48.57% | 41.43% | 48.00% | 42.00% |
| 换图后 ITT* | 34.29% | 34.29% | 26.00% | 42.00% |
| VWSD top-1 | 66.67%（14/21） | 42.86%（9/21） | **60.00%（9/15）** | **60.00%（9/15）** |
| VWSD MRR | 0.772 | 0.630 | 0.778 | 0.743 |

*换图指标仍参照原描述标签，是图像依赖诊断，不是换图后重新标注的任务准确率。VWSD 确认 top-1 的两模型区间均为 [33.33, 86.67]%，样本太少，不能断言能力相同。SigLIP−CLIP 确认 ITT 配对差为 +12 个百分点，区间 [−2, +28]，不足以确立稳定模型排名。

按五类分别看，确认集 CLIP 的 swap_att 为 1/10，SigLIP 为 5/10；swap_obj 两者均为 4/10，而 replace_obj 均为 9/10。它提示属性/角色绑定值得优先复核，但每格只有 10 例，这些是描述性分层，不作多重显著性宣称。

## 3. 三分类：冲突和未知不能混为一类

K0 是同一统一提示下的无知识条件。确认集 48 单元上准确率 **28/48=58.33% [43.75, 72.92]**，macro-F1=0.526。混淆矩阵行是官方标签，列是模型输出：

| gold \ prediction | contradiction | entailment | neutral |
|---|---:|---:|---:|
| contradiction | 2 | 0 | 14 |
| entailment | 0 | 15 | 1 |
| neutral | 0 | 5 | 11 |

模型把 14/16 个冲突判成未知，同时将 5/16 个未知判成支持。探索集也漏掉全部 24 个官方冲突。并非所有漏判都能归为模型缺陷：部分官方冲突涉及人物身份、部分官方支持涉及心理状态，和严格证据提示存在边界冲突；但复核到的黑衣/橙衣等直接视觉反证仍被判未知，不能全部用标签噪声解释。

这是“本 checkpoint + 此提示”的联合表现。没有在确认集上换提示追成绩，也没有评估更大模型、提示敏感性或解码方差，故不能声称普遍的模型固有缺陷。

## 4. 辞书对照：没有得到独立结构收益

只从 hypothesis 检索 WordNet 3.0：前两个有名词义项的非停用词，各取前两个义项及最多两个直接上位词。K1 与 K2 使用完全相同的义项 ID、定义、同义词和有向关系，顺序一致；K1 写成普通说明，K2 写成带类型三元组。它是**同事实控制**，不是拿信息更多的关系图和单句释义比较。所有提示都说明辞书事实不证明图中存在某物。

Kshuffle 是反转上位边方向的损坏知识控制，不是随机知识，也不保证语义合理。去图/换图条件保持原 gold 仅用于原标签一致率比较；不把控制条件的数字当新图片的真实准确率。

| 条件 | 探索 72：正确/总数 | 确认 48：正确/总数 | 确认 macro-F1 | 确认 neutral→entailment |
|---|---:|---:|---:|---:|
| K0 无知识 | 40/72（55.56%） | 28/48（58.33%） | 0.526 | 5/16 |
| K1 同事实普通释义 | 41/72（56.94%） | 26/48（54.17%） | 0.468 | 6/16 |
| K2 结构化关系 | 38/72（52.78%） | 27/48（56.25%） | 0.483 | 6/16 |
| Kshuffle 反向关系 | 38/72（52.78%） | 27/48（56.25%） | 0.483 | 6/16 |
| K0 去图* | 27/72（37.50%） | 21/48（43.75%） | 0.349 | — |
| K2 去图* | 26/72（36.11%） | 22/48（45.83%） | 0.368 | — |
| K2 换图* | 26/72（36.11%） | 17/48（35.42%） | 0.234 | — |

确认集配对差，单位为百分点：

| 比较 | 差值 [95% bootstrap CI] | 修复 / 退化 |
|---|---:|---:|
| K2−K0 | −2.08 [−8.33, +4.17] | 1 / 2 |
| K2−K1 | +2.08 [0.00, +6.25] | 1 / 0 |
| K2−Kshuffle | 0.00 [0.00, 0.00] | 0 / 0 |
| K2−K2 去图 | +10.42 [−4.17, +25.05] | 10 / 5 |
| K2−K2 换图 | +20.83 [+4.17, +37.50] | 15 / 5 |

K2 相对 K1 仅修复一个确认单元，探索集反而退化 3 个（−4.17pp）。更有区分力的负证据是：**120/120 的 K2 与反向关系输出完全相同，而 120/120 的提示指纹确实不同**。重新从私有知识重建的 840 个提示散列全部匹配记录；全部单元都有义项和关系，不是空知识造成的伪对照。观察到的零差异导致退化的 [0,0] bootstrap 区间，不能解释为总体等效性证明。

这说明当前方案未显示对正确边方向的有效利用；不证明优质、相关、正确消歧的辞书知识永远无用。机械覆盖不等于相关：例如动作词的名词义被检索为财产持有、侵蚀等无关概念；人类 Oracle 尚未执行。K1/K2 确认集知识 token 均值为 239.7/247.3，并非等长。只有一个小模型、一次冻结提示和简单名词检索，无法把所有效应归因于结构本身。

## 5. 错误分析：保留干净反例，也保留对研究假设不利的证据

先按固定规则检查 28 项（成功和失败都包括），再追加全部 3 个两模型共享的确认 XOR 单元及剩余 1 个 K2/K0 改变单元，共 32 个。记录在 `ai-review.jsonl`。这是单个 Codex 的实际图片检查；追加项明确为事后案例分析，不是独立盲评或数据噪声率估计。**没有人类复核、双人一致率或人工 Oracle，所有 human_review 仍为 pending。**

| 单元 | 真实观察与判断边界 |
|---|---|
| `scpp/replace_rel/959` | 熊在箱子前、箱子在熊后，视觉证据清楚；两个双编码器均随等义改写跨过负例分数，支持局部空间关系表达不稳。 |
| `vwsd/en/146` | 方向上下文对应风向袋（候选 4）；两模型都选普通袜子（7）。这是比总体 top-1 更清晰的共同义项错误。 |
| `esnli/3362592729.jpg#0r1c` | 图中主体穿黑衣，假设断言橙色服装；K0/K1/K2 均输出 neutral，存在可见反证漏判。 |
| `esnli/1806580620.jpg#1r5c` | 微笑和太阳镜与蒙眼皱眉冲突；K0 正确，K1/K2 退化成 neutral。结构化知识未修复此类反证。 |
| `esnli/116409198.jpg#4r1e` | 登山者持食物与餐具；K2 相对 K1 唯一确认修复。反向关系也给出同一答案，因此不能归功于正确关系方向。 |
| `esnli/313385842.jpg#4r1n` | 仓库与人物可见，但购物活动未确定；K0 neutral，K2 entailment。词汇知识可能强化场景联想，但这个个案不能证明内部机制。 |
| `scpp/replace_rel/1402` | 一只手摸羊头、另一只摸身体，所谓负描述也成立；不能把这一排名失败当干净模型反例。 |
| `scpp/replace_att/504` / `172` | 前者“普通/豪华”属主观程度，后者改写产生邻接对象附着变化；官方金标保留，语义归因需谨慎。 |
| `esnli/2629784415.jpg#4r1e` | 参观艺术品可见，“享受”属于心理状态推断；官方支持与严格视觉证据的边界不同。 |

仍保留明确成功：厕所黑座/白体、杯上而非刀上的骷髅图案、Wii 展台、单车坐垫义项等。不能把这些模型描述成完全没有属性绑定或消歧能力。没有用 AI 意见删除错误、修改 gold 或生成“校正后高分”。

## 6. 与已有工作的贡献边界

[K-LITE](https://papers.nips.cc/paper_files/paper/2022/hash/63fef0802863f47775c3563e18cbba17-Abstract-Conference.html) 已研究外部词典知识用于视觉语言学习；“加词典”本身不是新贡献。[Structure-CLIP](https://ojs.aaai.org/index.php/AAAI/article/view/28017) 使用场景图与结构化负例，本轮没有训练其目标，也不能声称复现或超过它。[CECE](https://proceedings.iclr.cc/paper_files/paper/2025/hash/7eeec4dffcfe4912482ffbf2ab8ddb41-Abstract-Conference.html) 已探索推理期蕴含/矛盾描述扩展，本轮更窄地比较固定 WordNet 事实的呈现与边方向。[READ-CLIP](https://proceedings.neurips.cc/paper_files/paper/2025/hash/1487b44589123633117fb27d10bebcda-Abstract-Conference.html) 面向改写一致性学习，本轮只测冻结模型。这里的交付价值是可审核的问题诊断和负对照结果，尚无可宣称的新训练方法或论文级创新成立证据。

[SememeLRM](https://aclanthology.org/2026.acl-long.224/) 面向词对关系分类和词汇蕴含，使用树状义原；本轮 WordNet 上位边不是完整义原树，其词汇任务收益也不能直接迁移为视觉证据收益。[Concept Bottleneck Models](https://proceedings.mlr.press/v119/koh20a.html) 学习显式概念中间层并允许概念干预；这里没有训练概念瓶颈。[BLIP-2](https://proceedings.mlr.press/v202/li23q.html) 训练连接冻结视觉/语言模型的 Querying Transformer；本轮既没有训练连接模块，也没有实现该架构。这些工作限定了后续方案需要证明的增量，不能只靠模块拼接来主张创新。

## 7. 资源、验证与可复现性

正式双编码器各 160 条注册记录（156 有效，4 隔离），Qwen 840 条；三个成功小试另各 20 单元，其中 Qwen 总生成 860 次。无外部按量付费推理 API、无参数更新。唯一权重约 8.93GB；下载重试和放弃的缓存不是额外模型。网络重试字节未完整计量，不把下载预算冒充精确网络费用。

| 正式运行 | 推理阶段墙钟 | PyTorch 峰值 allocated |
|---|---:|---:|
| SigLIP | 7.66 秒 | 0.90 GB |
| CLIP | 24.94 秒 | 0.65 GB |
| Qwen 七条件 | 246.07 秒 | 7.75 GB |

以上包含相应 CPU 预处理/记录开销，不是纯 GPU 时间；共享服务器、固定条件顺序和缓存热度使其不能用于模型速度排名。加载与散列核验时间、小试时间另存在 run JSON。下载阶段远大于推理阶段；最终使用另一个本地盘中转及内容一致的镜像，无清理其他实验。

公开结果完整性校验通过：所有 ID、gold、文本/图片指纹、模型权重与完整条件覆盖一致。新增测试验证严格 ties、invalid 分母、同事实控制、重复计数拒绝及篡改标签/删除条件拒绝；完整 CPU 回归结果见 `verification.json`。图片和知识全文只留本地，公开资料不含登录信息。

## 8. 研究决策与未完成边界

| 假设 | 当前判断 |
|---|---|
| H1 同义改写不稳定 | 基准层面已复现，部分清晰案例获 AI 视觉复核支持；总体错误中混有标注问题。 |
| H2 语义关系/角色绑定缺陷 | 有局部可重复证据；尚未覆盖完整方向性蕴含体系，也未做人工金标确认。 |
| H3 冲突与证据不足边界 | 此 Qwen 配置存在明显混淆；模型能力、提示解释与数据 convention 尚未完全分离。 |
| H4 结构化辞书超过普通释义 | **本次不支持**；相对普通释义增益不稳定，且反向边控制完全同输出。 |

**建议停止直接扩大当前“检索若干词义后拼接三元组”的训练/工程路线。** 下一阶段先用真实人类核验的相关义项和局部证据做小规模 Oracle，并在新的未查看样本上冻结提示复测；当前确认集不能再次充当调参后确认集。若干净数据和不同提示仍重复出现直接反证漏判，才值得考虑一个小型“局部证据支持/冲突/未知”判别模块。现有证据不支持先训练辞书图注入模块或微调整个骨干。

本轮完成真实基线和初步辞书对照，保留负结果；人工审核/Oracle、更强模型、感知去重、提示稳定性、相关知识检索上限及完整官方测试均未完成。草稿 PR 供人类研究复核，不自动合并，也不以文档代替这些尚缺的实验。
