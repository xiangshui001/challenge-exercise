# 01｜近期文献调研与选型

研究问题不是“找最大的模型”，而是“如何利用已有模型，以较小工作量完成可解释、可复现的检索质量优化”。检索与核验日期：2026-09-30；优先使用官方会议论文页、作者论文、作者代码和模型卡。来源编号见 [SOURCES](../references/SOURCES.md)。

## 2. 研究趋势如何变成可执行方案

### 2.1 不直接让通用多模态大模型承担全部检索

MM-Embed 的实证提醒我们区分“理解图文的能力”和“产生适合检索的表示”。据此，本项目不默认用 API 对全部图文组合逐对打分，也不直接用聊天模型某个隐藏层替代专用嵌入模型。[P1]

**本项目的设计推导**：先用预训练双编码器做全库初检，获得固定的候选列表；只有候选之间难以区分时，才使用交互式图文评分。这样能把强模型用于最可能影响最终排序的位置。这一推导是否改善 Flickr30K，需要本地验证，不能由论文摘要替代实验。

VLM2Vec 为更广泛的多模态查询提供候选方案，但当前只做自然图像与英文描述，不需要同时覆盖视频、文档、VQA 和分类。它留在备选清单，而不是新增必须完成的实验。[P2]

### 2.2 先把模型升级与排序方法的收益拆开

LamRA 原论文包含训练，不能称其整体“无需训练”。本项目采用的是其检索后重排的组织方式，并复用已经训练好的重排模型；“本项目不训练”与“所参考方法无需训练”是两回事。[P3]

**控制变量设计**：CLIP→SigLIP 2 只用于展示整体预训练配置升级。后续方法比较一律固定 SigLIP 2 编码器、数据、完整图库、Top-50 候选和重排器权重。这样，选择性重排与全量重排的差异才可归因于计算分配策略，而不是换了更大的骨干。

CLIP 与 SigLIP 2 同时存在模型规模、输入分辨率、训练数据及训练方式差异。报告只写“预训练模型配置替换的整体效果”，不声称证明某个单独模块的因果作用。

### 2.3 把近期的自适应思想压缩成一个小问题

WISER 原任务输入是参考图像和修改文本，使用双路候选与验证细化；不是纯文本查询 Flickr30K 的同一个问题。[P4]

**本项目仅研究一个简化问题**：使用现有检索分数估计查询在 Top-10 边界的歧义，对较难部分启用一次固定 Top-50 重排。无需生成新图片，无需循环反思，无需再训练门控器。其优点是可在既有分数上完成门控，容易加入随机同预算对照；缺点是边界间隔可能并不反映真实语义错误，所以必须允许负结果。

这里的“预算约束选择性重排”是课程实验中的方法设计与验证目标，不宣称算法首创，也不将 WISER 的公开提升幅度转述为本项目的预期提升。

### 2.4 不只关注是否进入前十

PinPoint 研究的是组合图像检索，不能直接套用其图库、指标或难度。它对改写和负例的关注提示我们：高配对命中率并不能证明模型理解了所有属性与关系。[P5]

**本项目的诊断设计**：正式主表仍采用固定 Flickr 配对真值；另抽取预先确定的查询，生成保真改写并人工复核，比较原句与改写的指标变化。错误案例同时检查数量、颜色、动作、关系等细节。诊断表单列，不用 API“认可”的新正例替换主表答案。

## 3. 为什么首选 SigLIP 2 与 Qwen 重排

SigLIP 2 提供现成图文编码器及官方权重。其技术报告表 1 的 Flickr 指标是 **Recall@1**：CLIP B/16、224 配置为 T2I 62.1 / I2T 81.9；SigLIP 2 So/14、384 配置为 85.7 / 94.9。这些是论文参考值，非本项目实测。它们仅支持“复用成熟权重具有可行性”的选型判断，不构成本项目达到 R@10≥85% 的保证。[T1]

默认强基线权重为 `google/siglip2-so400m-patch14-384`。严格使用它自己的处理器；“so400m”不应被当作完整图文模型总参数量来推导显存。选择固定分辨率版本，减少变分辨率配置工作。[T1][S2]

默认可选重排器为 `Qwen/Qwen3-VL-Reranker-2B`，使用官方相关性评分接口，而不是自行要求通用聊天模型输出一个任意 0–100 分。它是执行载体，不把其官方多任务平均成绩等同于 Flickr30K R@10。[T2]

## 4. 方案比较与取舍

以下等级属于本项目的工程判断，不是论文测得的统一成本排名。

| 方案 | 工作量判断 | 决策 |
|---|---|---|
| 冻结 CLIP 与 SigLIP 2，对齐评测 | 较低；主要是数据检查与编码 | 基础版必做 |
| 缓存排名上的 RRF 融合 | 较低；无新增模型推理 | 廉价可选对照，失败也保留记录 |
| SigLIP 2 + Qwen 2B Top-50 重排 | 中等；需要适配与候选评分 | 研究版先小试，收益与预算允许才全量 |
| 选择性重排 + 同预算随机对照 | 中等；重排缓存可复用 | 推荐研究重点 |
| LoRA 微调检索或重排模型 | 增加训练、划分与稳定性问题 | 首轮不做 |
| 全部查询逐对调用通用 API | 候选组合大、费用不透明 | 不采用 |
| 完整 WISER / PinPoint / MMEB 复现 | 任务变化明显，工程范围大 | 不作为实验五前置 |

## 5. 建议精读顺序及不确定性

优先阅读 LamRA 的两阶段流程、MM-Embed 对不同检索器的分析；随后阅读 WISER 的按需细化动机和 PinPoint 的评估设计。运行阶段主要查看 SigLIP 2 处理器说明、Qwen 官方接口、CLIP Benchmark 的检索指标实现。

本次不是对所有 2026 顶会的穷尽综述，也没有实测比较所有候选模型。部分 CVF 页面直接打开受访问限制，但正式会议页的标题、作者、会议信息可由官方索引核验，并用作者 arXiv 文本补充方法阅读。未核验来源不作为确定的发表事实；论文公开结果、任务差异和本项目假设始终分开。
