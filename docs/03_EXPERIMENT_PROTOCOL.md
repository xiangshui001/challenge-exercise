# 03｜实验与评测协议 v1.0（实施前草案）

本协议是本项目对课程未指定细节的补充。参数在验证阶段可以调整，但正式测试前必须另存冻结配置和变更理由。来源见[文献与工具清单](../references/SOURCES.md)。

## 1. 数据协议

主数据为 Flickr30K Karpathy 划分。[D1][D2] 计划规模如下，下载后必须校验：

| 划分 | 唯一图像 | 描述 | 用途 |
|---|---:|---:|---|
| val | 1000 | 5000 | 调试、参数选择和确认 |
| test | 1000 | 5000 | 冻结后的最终评测 |

训练划分不用于本地训练。每张图的五条描述各作独立文本，不拼接。每条 caption 保留唯一 caption_id 与 positive_image_id。图像候选表必须去除重复 ID，但不能因为模型表现不好删除样本。校验失败时停止，不静默丢弃坏图再沿用“标准 1000 图像测试集”的名称。

验证查询按图像分成 val_tune 和 val_confirm，各 500 张图及其全部描述，seed=2026；两组查询都面对完整 1000 张验证图像或完整 5000 条验证文本候选库。此划分是本项目内部参数管理方式，不是原始数据集官方新划分。最终指标仍在完整 test 协议上报告。

数据检查包含：val/test 图像 ID 不相交、文件可读、五描述对应正确、空文本检查、query/gallery 顺序清单、正例存在于候选库。额外记录相同图像内容或重复描述的情况，不在测试后根据成绩改变去重策略。

## 2. 方向与指标

T2I：5000 条文本查询 1000 张图像；每条查询有一个配对正例。I2T：1000 张图像查询 5000 条描述；每条查询有五个配对正例。

设查询 q 的标准正例集合为 Gq，前 K 个结果为 TopK(q)。本项目主表采用图文检索常用的命中式 R@K：[S1]

$$R@K=\frac{1}{|Q|}\sum_{q\in Q}\mathbf{1}\{TopK(q)\cap G_q\ne\varnothing\}.$$

另需集合召回率时，使用不同字段 `set_recall_at_k`：

$$SetRecall@K=\frac{1}{|Q|}\sum_q\frac{|TopK(q)\cap G_q|}{|G_q|}.$$

二者不能混淆。T2I 单正例时相等，I2T 通常不相等。主指标是 T2I R@10≥0.85；辅助报告双向 R@1/5/10 与 NDCG@10，不通过平均两个方向来掩盖主方向未达标。

NDCG 主表采用二值配对相关性 rel∈{0,1}：

$$DCG@K=\sum_{j=1}^{K}\frac{rel_j}{\log_2(j+1)},\qquad NDCG@K=DCG@K/IDCG@K.$$

IDCG 使用完整正例集合计算，不能只按已经找回的正例计算。I2T 的 IDCG 最多包含五个正例折扣项。参考 sklearn 的标准实现，单元测试核对理想排序、错误排序、多正例和并列分数。[S4]

候选 ID 先按固定字典序排列，分数降序使用稳定排序，作为并列分数的确定性处理。NaN、Inf、缺少正例、重复 ID、形状不匹配应报错。主表范围为已标注配对相关性，不声称所有未配对图片语义上都错误。

## 3. 模型与编码

B0：`openai/clip-vit-base-patch16`；B1：`google/siglip2-so400m-patch14-384`。模型各自使用原生 processor、固定 eval 模式和无梯度推理。SigLIP 2 使用小写文本、max_length=64 与 max_length padding，超长文本计数并记录截断；自然语言描述不擅自套零样本分类类别模板。[T1][S2]

图像与文本分别编码，转换 FP32 后做 L2 归一化，缓存特征及 ID 顺序。得分 S=T Iᵀ；这是完整候选库上的精确检索。B0/B1 的精确内积矩阵可直接转置用于反向检索，但任何依赖“每个查询的排名”的融合或重排必须分别按检索方向重新计算。

## 4. 方法编号与最小对照

| 编号 | 定义 | 地位 |
|---|---|---|
| B0 | CLIP 精确检索 | 基础版必做 |
| B1 | SigLIP 2 精确检索 | 基础版必做、研究版固定初检器 |
| F1 | B0 与 B1 的加权 RRF | 可选廉价优化 |
| R1 | 固定 B1 Top-50，对全部查询用 Qwen 2B 重排 | 研究版参考；“全量”指全查询，不是全图库逐对评分 |
| G25 / G50 | 固定 B1 Top-50，按验证阈值选择约 25% / 50% 查询重排 | 研究版候选 |
| RAND25 / RAND50 | 与 G 方法实际启用查询数相同的随机选择 | 必要的计算量控制对照 |

重排研究默认只做 T2I，I2T 保留 B0/B1/F1 对照即可。不得因采用 F1 就随意更改研究版初检器；需要改动时增加独立消融。

### 4.1 廉价排名融合 F1

采用加权 RRF 的设计变体：[P6]

$$f(q,i)=\frac{w}{60+r_{B1}(q,i)}+\frac{1-w}{60+r_{B0}(q,i)}.$$

rank 从 1 开始。验证候选权重 w∈{0,0.25,0.5,0.75,1}，包括单模型端点。不假定融合必然胜出；未提升时最终方案可选择 B1。

### 4.2 重排 R1

首先检查 B1 的 R@20、R@50，估计候选覆盖空间。对每条查询选前 M=50 张图，输入查询原文及候选图像像素；不输入配对描述、标注、原始答案位置。使用 Qwen 官方 pointwise 评分实现。[T2]

重排打分后，可用排名融合避免未经校准的原始分数直接相加：

$$h(q,i)=\frac{1-\lambda}{60+r_{B1}^{(M)}(q,i)}+\frac{\lambda}{60+r_{Qwen}^{(M)}(q,i)},\ i\in TopM(q).$$

λ∈{0,0.5,1} 在 val_tune 比较，val_confirm 复核；Top-M 外候选原顺序不动。λ=0 为不变对照，λ=1 为纯重排。不额外扩大超参数网格。Qwen 分数不是经本数据集校准的正确率。

仅重排 Top-10 内部不会改变 R@10。仅重排 Top-M 有上界：

$$R@10_{after}\le R@M_{before}.$$

若正确图片未进入 Top-M，再强的该阶段重排也无法找回。

### 4.3 选择性计算 G25/G50

定义一个无需标签的候选启发式：

$$g(q)=\frac{s_{(10)}-s_{(11)}}{std(s_{(1)},\ldots,s_{(50)})+10^{-8}}.$$

其中 s 是 B1 的余弦得分。g 小表示 Top-10 边界较难区分，**不代表已验证的错误概率**。在 val_tune 根据 g 的 25% / 50% 分位数确定阈值，在 val_confirm 检查启用比例和效果，然后冻结阈值应用于测试。阈值迁移后实际比例可能偏离 25% / 50%，必须报告实际值；不能宣称天然满足精确比例预算。

为应对显式硬预算，执行程序另设 max_pairs，达到上限停止并记录未执行项；不把未执行项删出查询分母。固定阈值是默认评测方案，硬截断发生时须将结果标注为截断预算版本，并按该实际数量建立随机对照。

RAND 方法以相同启用查询数随机抽样，seed∈{0,1,2}。门控、随机、全查询方法复用同一候选与评分。门控不得读取正例排名、基线 hit 标签、人工答案或 API 对标准答案的分析结果。

该公式和预算实验为本项目设计；与 WISER 仅有按需分配计算的思想联系，不自称复现其完整方法。[P4]

## 5. 参数选择、消融和停止规则

选择顺序固定：先 B0/B1 数据与处理器检查；再 F1 廉价对照；研究版先确定 λ，再比较两个门控预算，不做权重、候选数、分辨率和预算的全部笛卡尔组合。

主选择标准为 val_tune T2I R@10，其次 NDCG@10，其次更少重排对数。val_confirm 用于一次确认而不是反复返调。R1 若没有正净收益或速度不可接受，则保留负结果，停止研究扩展；可以在报告讨论启发式限制，无须强行引入训练。

核心消融为 B1、R1、G25/G50、匹配预算 RAND。M=20 仅作为有余力时的单因素补充，不能在测试成绩出来后再选择最有利的 M。替换骨干、额外文本生成、提示词调优分别记为新增变量。

## 6. 统计与成本

每种方法保存逐查询指标。95% bootstrap 区间默认重复 2000 次，seed=2026。T2I 按 image_id 分组，同图五条描述一起重采样；I2T 按图像查询重采样；固定图库不重采样。方法差异采用相同分组抽样计算配对差值区间。

记录 R@10 修复数 b、退化数 c，净变化为 (b-c)/Q；只展示修复案例不足以证明总体提升。门控随机种子的波动不是模型训练种子方差，因为本项目无训练。

成本分三类：一次性图文编码、实际重排候选对计算、可选 API 请求。每类分别记录墙钟时间、GPU 时间口径、峰值显存和调用/图文对数。用缓存模拟策略时记 `cost_mode=counterfactual_from_cache`；实际运行记 `measured`。模型加载和下载是否计时必须写清。

预算判断可用“启用查询比例”和“候选对数”这一透明代理量，但候选对数减少不必然产生同比墙钟加速。最终需要实测的策略应重新跑一遍该实际执行路径，不能从缓存读取时间报告模型推理加速。

## 7. 独立诊断

可选改写集合：在查看改写模型成绩前，按 seed=2026 从 test 预选 200 张图，每图随机取一条描述；每条生成两种保真改写，经人工复核后冻结。原句、改写 1、改写 2 使用同一完整测试图库，报告均值变化和三种表达中最差表现。因标注歧义排除的条目须逐项记录原因及总数，不可按检索成绩排除。[P5]

人工相关性审查不修改正式 Gq。若标注联合候选池，则未审查项保持 unknown；仅报告带池范围和覆盖率的诊断指标，不宣称得到全图库新真值召回率。

## 8. 冻结清单

正式测试前锁定：数据版本及 ID 清单、模型 revision、代码版本、处理器参数、候选 M、λ、门控阈值、随机种子、指标口径、API 提示词版本、预算和失败处理策略。将配置及记录一并存档。测试后只允许明确标注的错误修复重跑，不把一次次测试集调参写成单次独立验证。
