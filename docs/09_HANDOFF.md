## 配置接口注意事项

模型 revision、数据路径、门控阈值、API 预算目前有 null 值。实现应区分必需字段和未启用功能：正式运行时必需字段未填应报错；未启用 API 时不得读取或要求密钥。不要为了“能跑”把未设门控阈值自动替换成 0，也不要把 null 指标变成 0。

## 建议本地目录

未来数据放 `data/local/`，权重放 `models/` 或外部缓存，特征放 `cache/`，运行与 API 原始日志放 `runs/`。上述大文件或敏感目录已被忽略。可公开的最终小型汇总进入另建的 `results/`，每次提交前审查文件，不上传原始图像或账户信息。

## 完成状态更新规则

任务完成必须同时更新实际文件、运行记录和 `docs/00_SCOPE_AND_STATUS.md`。只有文档或接口写好，不等于模型已运行；只有模型跑通小样本，不等于正式测试完成；只有正式指标达到阈值，也不能省略错误分析。后续对外总结遵守同样区分。
